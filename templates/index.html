SILO Job Allocation

Turns raw OpenStreetMap buildings, landuse and POIs into per-zone job counts — the borough/parish, buildings, POI and jobLocation stages, run end to end without QGIS.

01

Borough

Assign each TAZ zone its borough via a centroid-in-polygon join. Replaces add_borough_BBSR.ipynb.

02

Buildings & Landuse

Pulls buildings + landuse from ohsome, removes overlaps, merges the layers, classifies by type (1–10) and computes job area % per zone.

03

POI polygons

Fetches POI polygons, fixes geometry, splits across zone borders and tags job type + percentage.

04

POI points

Fetches POI points, joins TAZ/gemeinde IDs and tags job type + percentage.

05

POI point area

Assigns each POI point an area: same TAZ+class average → same municipality+class average → global class average. Observation towers are folded into communications towers for this step only.

06

Clean POIs

Removes POI points/polygons that overlap the building/landuse layer, then drops points sitting inside a same-class polygon.

07

jobLocation

Combines cleaned POI points/polygons and building/landuse job elements into one job-location table with x, y coordinates.

08

jobAttributes

Aggregates job area by zone and municipality, allocates municipality job population down to zones, and merges the result into your zone attribute table.

Runs locally against geopandas + the ohsome API — no QGIS session required.
